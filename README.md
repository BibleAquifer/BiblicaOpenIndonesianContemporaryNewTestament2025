# _Biblica® Open Indonesian Contemporary New Testament 2025_ Aquifer Resource

This repository (`BiblicaOpenIndonesianContemporaryNewTestament2025`) contains an Aquifer Bible resource with resource-level metadata and content files in USFM and USX formats.
